Missão Rover Lunar
Este projeto contém o código base para o sistema de controle de um Rover Lunar. O objetivo principal é inicializar os sistemas vitais do robô para exploração.

Funcionalidades
Verificação de status dos sistemas.
Monitoramento de painéis solares.
Verificação do nível da bateria.

Como utilizar
Compile o arquivo rover.java.
Execute a classe Rover.
